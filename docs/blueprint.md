# **App Name**: Gameday

## Core Features:

- User Archetype Onboarding: Users can define their sport, primary position, key abilities, and areas for improvement through interactive forms to build a personalized sports profile.
- Premium Access Management: Manages display of subscription benefits and pricing, facilitates free trial initiation, and integrates league syncing options.
- Dynamic Weekly Countdown: A prominent dashboard display showing a real-time countdown to upcoming games with critical details like opponent and time.
- AI-Powered Personalized Training Tool: Generates and presents daily training drills and nutritional recommendations tailored specifically to the user's profile, position, and areas for development, along with supporting media.
- Drill Library & Tracking: Allows users to deep-dive into video demonstrations and step-by-step instructions for specific drills, and mark them as completed to track progress.

## Style Guidelines:

- Background color: A deep, neutral charcoal (`#121212`) provides a sleek, high-contrast canvas for content, aligning with the dark mode aesthetic requested.
- Primary accent color: A vibrant 'electric neon green' (`#33FF77`) derived from HSL (H: 140, S: 100%, L: 60%), used for primary call-to-actions, active states, and critical highlights to convey energy and professionalism.
- Secondary accent color: An energetic lime-green shade (`#75A314`) derived from HSL (H: 110, S: 80%, L: 40%), used for secondary highlights, metadata tags, and complementary UI elements, offering an analogous yet distinct contrast.
- Headlines and prominent text: 'Space Grotesk' (sans-serif) for a bold, modern, and athletic feel, ensuring impactful headings like 'Build Your Archetype' and 'GAMEDAY MINUS 2'.
- Body text, numbers, and data: 'Inter' (sans-serif) for its ultra-clean readability, making detailed instructions, value propositions, and metrics easy to digest.
- Crisp, modern vector icons, potentially with an outline or minimalist fill style. Utilize the primary electric green for interactive states, 'PRO' badges, and checklist indicators.
- A high-contrast dark mode theme featuring solid layout cards with subtly rounded corners. Consistent spacing and visual hierarchy across all screens maintain a premium, athletic, and cohesive user experience.
- Subtle and fluid animations, particularly for screen transitions, button interactions, and status updates, enhanced with a glowing effect around interactive elements, contributing to an energetic and responsive feel.
